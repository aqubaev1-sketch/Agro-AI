# 🌱 ФитоДоктор AI (PhytoDoc) — Диагностика болезней растений по фотографии

Минималистичный веб-сервис для стартапа по экспресс-диагностике фитопатологий растений с помощью нейросетей. Позволяет за 3 секунды определить заболевание листа, получить процент уверенности модели, перечень внешних симптомов и пошаговый протокол лечения (биопрепараты + агрохимические средства).

---

## 🚀 Стек технологий

- **Фреймворк**: Next.js 15+ (App Router, TypeScript)
- **Стилизация**: Tailwind CSS 4 + компоненты со стилем shadcn/ui
- **База данных и Auth**: Supabase (PostgreSQL + Supabase Auth)
- **API**: Route Handlers Next.js (`/api/predict`, `/api/subscription`)
- **Иконки**: `lucide-react`
- **Анимации**: `motion`

## 🛠️ Быстрый старт и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения (опционально)
Скопируйте пример файла окружения:
```bash
cp .env.local.example .env.local
```

Заполните ваши ключи из консоли [Supabase](https://supabase.com):
```env
NEXT_PUBLIC_SUPABASE_URL="https://your-project-id.supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```
> **Примечание**: Сервис спроектирован так, что если переменные окружения не заданы, приложение автоматически переключается в **демо-режим**: в интерфейсе доступен быстрый вход в 1 клик со всеми возможностями, локальным сохранением истории и симуляцией лимитов.

### 3. Запуск сервера разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🌿 Функциональность MVP

### 1. Экспресс-диагностика (`/diagnose`)
- Drag & Drop и выбор файла любого формата (JPEG, PNG, WebP)
- 3 готовых образца в 1 клик для быстрого тестирования:
  - Томат (Альтернариоз)
  - Монстера (Краевой хлороз)
  - Яблоня (Парша)
- Запрос к `/api/predict` с реалистичной симуляцией работы нейросети (сканирование, сегментация контура листа)
- Карточка результата с фото, патогеном, латинским названием, % уверенности, тяжестью поражения, перечнем симптомов, планом лечения (органика/препараты) и профилактикой.

### 2. Тарифные планы (`/pricing` & `components/PricingCard.tsx`)
- **Free**: $0, 5 диагностик/месяц, базовый функционал
- **Basic**: $5/мес, 100 диагностик/месяц, подсвечен как популярный выбор
- **Pro**: $15/мес, без ограничений, экспорт отчетов в PDF, доступ к REST API
- Кнопки отправляют запрос на `/api/subscription` и отображают информативный alert.

### 3. Личный кабинет пользователя (`/profile`)
- Профиль: имя, аватар, email, дата регистрации
- Счетчик диагностик: отображает количество использованных проверок в текущем месяце (например, 2/5)
- Интерактивная история всех прошлых проверок с возможностью раскрыть полное архивное заключение.

## 🔌 Подключение реальной ML-модели в будущем

Для перехода от мок-данных к реальной модели компьютерного зрения (например, PlantVillage ResNet-50 / EfficientNet / Gemini Vision API):
1. Откройте файл `app/api/predict/route.ts`
2. Замените вызов `generateMockPrediction(seedHint)` на вызов вашего микросервиса инференса (TorchServe, FastAPI или Google Vertex AI)
3. Формат возвращаемого ответа остается совместимым:
```json
{
  "plant": "Томат",
  "disease": "Альтернариоз",
  "confidence": 96,
  "symptoms": ["Коричневые пятна на листьях"],
  "treatment": ["Обработать биофунгицидом"]
}
```
